a11y-behaviors

A11yBehaviors is a mixin (not a custom element) that adds accessible text-contrast helpers to a LitElement class. It exposes getTextContrastColor(bgColor), which returns #ffffff or #000000 based on the luma of a supplied hex background color, and computeTextPropContrast(textProp, bgProp), which reads a background-color property off the host and writes an accessible text color to another property.

Because this is a mixin function, there is no real <a11y-behaviors> element to instantiate. Instead, it is applied to another class via function composition, as shown below.

Usage example

import { LitElement, html, css } from "lit";
import { A11yBehaviors } from "@haxtheweb/a11y-behaviors/a11y-behaviors.js";

class MyAccessibleCard extends A11yBehaviors(LitElement) {
  static get properties() {
    return {
      backgroundColor: { type: String },
      textColor: { type: String },
    };
  }

  constructor() {
    super();
    this.backgroundColor = "#003366";
    this.textColor = "#000000";
    // computes an accessible textColor based on backgroundColor
    this.computeTextPropContrast("textColor", "backgroundColor");
  }

  render() {
    return html`
      <div
        style="background-color: ${this.backgroundColor}; color: ${this.textColor};"
      >
        Content with automatically computed contrast
      </div>
    `;
  }
}
customElements.define("my-accessible-card", MyAccessibleCard);
