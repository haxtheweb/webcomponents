user-scaffold demo

user-scaffold is a headless singleton that quietly builds short and long term memory of user interactions. It listens for trusted clicks, drags, and drops, tracks how long it has been since the last interaction, and exposes readMemory, writeMemory, and deleteMemory methods plus a computed memory object that other elements can react to. It renders no interface of its own, and importing the module is enough to put the singleton on the page.
