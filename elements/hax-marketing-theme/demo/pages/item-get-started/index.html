The commands you will use most

Everyday HAX commands
CommandWhat it does
hax startPick what to make from a menu
hax site my-siteCreate a site
hax serveRun the site you are in, with the editor
hax site node:add --title "About"Add a page
hax site site:surge --domain my-site.surge.shPublish to Surge
hax webcomponent my-blockStart a new block
hax auditCheck a block against the design system
hax updateUpdate the CLI
