Credit where it is due. The platforms compared: WordPress, Drupal, Ghost, Squarespace, Wix, Hugo, Astro, 11ty, Notion, Canvas.

The short version, platform by platform

WordPress wins on recognition and plugin count. The cost is a database, a PHP runtime, perpetual security patching, and content locked in a schema only WordPress reads well. HAX is flat files that run on PHP, Node or the CLI with identical output, so nothing rots when a plugin is abandoned. The WordPress and Elementor importers are the on-ramp.

Drupal's pitch is structured content and enterprise governance. The price is complexity, a dedicated site builder role, and painful major upgrades. In HAX the structure lives in the web components themselves, so authors get rich, accessible blocks without a builder layer, and a single instructor or small team can maintain it.

Polished and easy, but you rent the experience. Ghost is primarily a newsletter engine; the hosted builders export little of value. HAX matches the on-page editing ease while you keep the files, can publish static anywhere, and everything is Apache-2.0.

Fast, portable, developer-loved, and closed to non-technical authors because there is no editor. HAX delivers static-friendly output plus in-browser WYSIWYG authoring.

Great for drafting, weak for durable, discoverable, accessible publishing. HAX's education focus, OER sites, course content and Common Cartridge import, is a differentiator none of the general-purpose CMSs have.

Where the others win today

  • A larger community and more turnkey integrations: e-commerce, membership, forms marketplaces.
  • No learning curve around web components and blocks if you already think in page builders.
  • Name recognition outside education and open source.
