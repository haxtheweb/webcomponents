One short answer to "why is this for me", by who is asking.

Build course sites and OER that outlive the LMS. Import a Canvas export (Common Cartridge), get accessible, print-friendly, discoverable pages, and keep the content when the contract changes. Every page is also xAPI-aware for learning analytics.

A portfolio, club, band or shop-front site that looks good out of the box, ranks in search and AI answers, and costs nothing to keep online. The same on-page editing as Wix, with files you own.

HAX removes the two things that make a CMS expensive to own: a database to secure and a plugin ecosystem to patch. Sites are flat files on a defined contract, so you run it on the stack you already operate, host hundreds of sites from one HAXiam deploy, publish static copies for disaster recovery, and walk away with every file if you ever stop. Penn State runs it at hax.psu.edu.

One command gets you a site, and you choose PHP, Node, or a static publish to GitHub Pages, Netlify or Surge. No database, no cron, no subscription. Your content is HTML and JSON you can open in any editor and version in git. If HAX disappeared tomorrow your site would still work.

A machine-readable content model, deterministic CLI commands, an OpenAPI contract, an MCP server, and skills that tell you how to do the job correctly and accessibly.

Ship a standard web component once and it becomes an authorable block in every HAX site. The HAX schema, DDD tokens and the coming plugin architecture give you a distribution channel without framework lock-in.

A client site you can hand over completely: no hosting dependency, no license fee, no database to babysit. Migrate from WordPress, Elementor or static generators, theme it with DDD, and bill for the work, not the subscription.

Government, libraries, museums and nonprofits need WCAG compliance across hundreds of pages maintained by non-specialists. HAX builds accessibility into every element and theme and can report on it from the content itself, so compliance is the default rather than an audit finding.

Embed HAX authoring or rendering inside your own product. Apache-2.0, a framework-agnostic editor, an OpenAPI backend contract and a CLI make it an engine you can build on without relicensing your product.
