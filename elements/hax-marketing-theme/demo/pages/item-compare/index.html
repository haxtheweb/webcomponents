How to read this. Each open project was scored 0 to 5 in one pass from its public repository and project pages, then counted as evidenced (3 or more: written down and practiced), partly (1 or 2) or a gap (0). Hugo, Astro, 11ty and Canvas were scored from their repositories without a web search pass, so practices that live only on their websites may be under-counted. Closed platforms score 0 because none of the 47 questions can be answered from the outside. It is not an official HEOSAT score.
