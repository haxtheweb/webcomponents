HAX is the open web, built from plain text and blocks that anyone can edit. Each block is a web component.

Same blocks, same editor, which reads each component's schema. Run it as a single site, multisite or multi-tenant, or publish plain static files.

The magic script loads each element once. Later pages only fetch what is new, so every follow-up request is faster.

Seven community pillars hold it up for students, designers, educators, developers and AI agents: accessible, extensible, free and open, efficient, platform agnostic, remixable and sustainable.

So what will you launch? A docs site, a portfolio, a website, a blog, a course. Everyone gets a rocket, and our pillars are your engines of change!

Everything HAX makes meets accessibility standards by default, so authors don't need to be experts to publish work everyone can use. Blocks are tested for contrast, keyboard use and screen readers before they ship, and meaning never depends on color alone. HAX also reaches a global audience, with an interface in over 100 languages. And since you don't need to know what the web is to use it, anyone can contribute.

Authors build sites in minutes, not weeks, and agents can handle the repetitive work. Pages load only what they need, so they're fast on any connection or device. The less time we spend waiting and trying to figure out how to use something, the more time we spend dreaming the future together.

Every block and theme in HAX is a web component, so new ones follow the same rules as the ones we ship. Plugins add choices and integrations without changing the core. And because HAX can understand any block's settings, anything you build works in the editor right away.

HAX is free, open source under Apache 2.0, and built on open standards like web components, OpenAPI, WCAG and xAPI instead of a proprietary framework. Your site is plain HTML files you can take anywhere, with no lock-in and no subscription. What you make is yours to keep, change, share or move, however you see fit.

Bring content in from Word, PDFs, old sites or other CMSs, and HAX turns it into clean web pages. Those pages work on phones, tablets, laptops and big screens, in light or dark mode. Run it on PHP, Node, the command line, the desktop app, or as a static site with no server at all.

Every page is made of blocks you can rearrange, reuse or pull into another site. Bring in PDF, DOCX, PPTX, XLSX, HTML or Markdown, and export to PDF, EPUB and other open formats. Change the theme any time and your content comes along untouched, and anything an agent makes stays fully editable by a person.

Nearly every site built since 2020 still works today, and new features reach old sites through upgrades, without rebuilds. Sites are small, load only what they need, and can run as static files, which saves energy on every visit. And the project is built to outlast any one person, with its knowledge recorded so the community can carry it forward.

Why they matter

A pillar is a promise you can check. If a block ships without keyboard support, it is not Accessible. If a plugin locks your content in, it is not Free and open. The pillars are how a small team, students and agents all make the same call without asking.
