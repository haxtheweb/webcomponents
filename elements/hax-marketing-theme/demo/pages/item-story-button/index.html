What it is

A claim is easier to believe when you can see where it came from. This button sits beside a number, a pillar, a person or a block, and takes you straight to that story on hax.cloud. Same mark, same words, on every site.

On any HAX site

It is a block. Give it the story's address on hax.cloud. The address never changes, even when the story is renamed.

Use the small one inside a sentence or a list.

In a GitHub README

A README cannot run a block, so there it is a badge that links to the same story.

In the block gallery

Every block in the gallery gets one, so you can go from its documentation to the pillars and stories it belongs to.

Each story on hax.cloud has its own address (hax.cloud/stories/ee450a19), and a whole web keeps a readable path (hax.cloud/hax-lab). The badge address is where the file would live once this site is real.
