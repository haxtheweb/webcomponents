utils

@haxtheweb/utils is a plain JavaScript utility library, not a web component or mixin. It re-exports a collection of small, dependency-light helper functions (from lib/*.js) used throughout the HAX ecosystem for clipboard access, URL sanitization, ID generation, markdown detection/conversion, object path traversal, selection/range handling, and more. Below are usage examples for a few representative exports.

copyToClipboard

Copies a string to the clipboard and dispatches a toast notification event on success or failure. 

import { copyToClipboard } from "@haxtheweb/utils/utils.js";

async function shareLink(url) {
  await copyToClipboard(url, "Link copied to clipboard");
}

sanitizeEmbeddableURL

Validates and sanitizes a URL before it is used as an iframe/embed source, rejecting unsafe protocols. Used internally by media-behaviors when normalizing video embed sources. 

import { sanitizeEmbeddableURL } from "@haxtheweb/utils/utils.js";

const safeSrc = sanitizeEmbeddableURL(userSuppliedURL, "");
// safeSrc is "" if the input was unsafe/invalid, otherwise a safe URL string
if (safeSrc !== "") {
  iframeEl.setAttribute("src", safeSrc);
}

generateResourceID

Generates a unique resource identifier string, used by schema-behaviors to assign a stable resource attribute to elements participating in RDFa schema markup. 

import { generateResourceID } from "@haxtheweb/utils/utils.js";

const resourceId = generateResourceID(); // e.g. "#3f9a1c2b-...-..."
element.setAttribute("resource", resourceId);

See utils/lib/clipboard.js, utils/lib/url.js, and utils/lib/ids.js for the full implementations, and utils/utils.js for the complete list of exports.
