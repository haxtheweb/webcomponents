DDD palettes are set with data-primary and data-accent. Each named DDD color points at the Tailwind palette color with the same role, so the palettes stay distinct.

DDD beaverBlue → Tailwind blue 600.

DDD nittanyNavy → Tailwind blue 900.

DDD creekTeal → Tailwind teal 600.

DDD wonderPurple → Tailwind purple 800.

An accent surface: DDD slateMaxLight → Tailwind slate 50.

An accent surface: DDD limestoneMaxLight → Tailwind gray 50.
