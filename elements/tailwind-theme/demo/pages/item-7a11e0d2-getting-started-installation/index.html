The theme ships with HAX, so there is nothing extra to install. Pick the way you work and follow the steps.

Installation

Start a new site with the HAX command line.

Set the theme in site.json.

Run the site locally and edit pages in the browser.

In the editor, open the site settings.

Choose Tailwind from the theme list and save.

Check the result

Blocks you already use pick up the Tailwind palette, type and radii. Nothing in your content changes.
