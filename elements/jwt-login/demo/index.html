jwt-login demo

jwt-login is a headless element that requests, stores, refreshes, and clears a JSON web token for a site. It renders no interface of its own; instead it manages the jwt property and dispatches jwt-token, jwt-logged-in, and jwt-changed events that other elements can react to. Both snippets below are fully offline: no request fires unless the auto flag is combined with a url, or a login, logout, or refresh event is dispatched against a configured url.
