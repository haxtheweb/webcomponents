About baseline-build-hax

baseline-build-hax is not a visual web component and does not define a custom element of its own. It is a HAX build/app-configuration aggregator: a single JavaScript entry point that imports and registers a curated baseline set of elements needed to run a HAX authoring app (editor toolbar, tray, app picker, and a starter library of HAX-capable content elements).

Importing baseline-build-hax.js in an app bundles together the following elements:

  • wysiwyg-hax
  • cms-hax
  • hax-body
  • hax-store
  • hax-autoloader
  • hax-tray
  • hax-app-picker
  • hax-app
  • hax-toolbar
  • a11y-gif-player
  • citation-element
  • image-compare-slider
  • license-element
  • lrn-math
  • lrn-table
  • lrn-vocab
  • oer-schema
  • media-behaviors
  • media-image
  • meme-maker
  • multiple-choice
  • person-testimonial
  • place-holder
  • q-r
  • self-check
  • stop-note
  • video-player
  • wikipedia-query
  • grid-plate

Because this package has no markup or styling surface of its own, there is nothing to render in a live demo here. To see these elements in action, visit each element's own demo page, or use a HAX authoring app that imports baseline-build-hax.js directly.
