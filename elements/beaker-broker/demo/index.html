beaker-broker demo

beaker-broker brokers reads and writes to a Beaker browser DAT archive. Outside the Beaker browser the global DatArchive API is unavailable, so the broker logs a warning and stays a plain container; inside Beaker it turns the dat-url attribute into an archive object and exposes read and write methods against it.
