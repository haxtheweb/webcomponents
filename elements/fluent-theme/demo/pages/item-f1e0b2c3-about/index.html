The token values are read from @fluentui/tokens 1.0.0-alpha.24 (MIT), the token package Fluent UI React 9 builds its themes from (fluent2.microsoft.design). Fluent publishes its tokens as JavaScript; the bridge reads their literal values and keeps Fluent's own CSS names. No Fluent stylesheet or script is loaded.

Icons are Fluent UI System Icons (MIT), copied for the HAX icon names the bridge maps.
