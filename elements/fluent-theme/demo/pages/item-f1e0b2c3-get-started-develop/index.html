Two ways to use it

Choose Fluent 2 from the theme list in site settings. The layout and the blocks both take on Fluent.

Keep a theme such as Clean One and pick Fluent 2 as the design system. Blocks take on Fluent colors, type and corners inside your layout.

Blocks read DDD tokens and the bridge answers with Fluent values, so nothing in your content changes.

Set it in site.json
