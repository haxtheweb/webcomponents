The token values on this site are generated from the U.S. Web Design System (designsystem.digital.gov): @uswds/uswds 3.14.0, the color maps in packages/uswds-core/src/styles/tokens/color. USWDS is a work of the U.S. government, in the public domain in the United States and dedicated worldwide under CC0 1.0. The values are re-expressed under their own names (--usa-blue-vivid-60 is USWDS's blue-60v). No USWDS stylesheet or script is loaded.

Type follows the USWDS default theme roles: Source Sans 3 for body and interface text, Merriweather for headings and Roboto Mono for code, loaded from Google Fonts (SIL Open Font License 1.1 and Apache-2.0).

This theme is an independent HAX integration. It is not affiliated with or endorsed by the General Services Administration or any U.S. government agency, and it does not include the official government banner, agency seals or identifiers, which are only for real federal websites.

Coverage

Identity 94% (all 52 named colors, fonts, three weights, three radii, shadows and focus), semantic 42% (density from USWDS card and button spacing), feel 0% (USWDS defines no motion or state tokens). Structure stays DDD, and so do heading and body sizes.

The full map ships as lib/uswds.ddd-map.json.
