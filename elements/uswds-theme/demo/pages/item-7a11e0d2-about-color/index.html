DDD palettes are set with data-primary and data-accent. Each named DDD color points at the USWDS system color its default theme gives that role, so the palettes stay distinct.

DDD beaverBlue → USWDS blue-60v (primary).

DDD nittanyNavy → USWDS blue-warm-70v (primary-dark).

DDD creekTeal → USWDS mint-cool-50v.

DDD wonderPurple → USWDS violet-70v.

An accent surface: DDD slateMaxLight → USWDS gray-cool-5.

An accent surface: DDD limestoneMaxLight → USWDS gray-5 (base-lightest).
