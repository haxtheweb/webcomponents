This site runs on uswds-theme, a HAXcms theme in the U.S. Web Design System layout: a basic header, side navigation and a slim footer. It sits on top of the USWDS DDD bridge.

How the bridge works

Every HAX block reads DDD tokens such as --ddd-theme-default-beaverBlue, --ddd-font-primary and --ddd-radius-sm. While USWDS is the active design system those tokens point at the USWDS palette and default theme, so the whole block ecosystem takes on USWDS colors, Source Sans and Merriweather, radii, shadows and its thick focus outline without any block changing.

Content stays plain DDD content. Switch this site to any other theme and every page keeps working.
