media-behaviors

This package exports MediaBehaviorsVideo, a mixin (not a custom element) that adds helpers for resolving and normalizing video sources from multiple providers (YouTube, Vimeo, Twitch, Sketchfab, Kaltura MediaSpace, and local file references). It exposes getVideoType(source) to identify the provider, cleanVideoSource(input, type) to rewrite copy-pasted share URLs into clean, cookie-free embed URLs, and _sourceIsIframe(source) to determine whether the source should render in an <iframe> or a local <video> tag. The module also attaches an equivalent, globally accessible copy at globalThis.MediaBehaviors.Video for non-mixin consumption.

Because MediaBehaviorsVideo is a mixin function, there is no real <media-behaviors> element to instantiate. It is applied to another class via function composition, as demonstrated by the real consumer video-player.

Usage example (adapted from video-player.js)

import { LitElement, html } from "lit";
import { MediaBehaviorsVideo } from "@haxtheweb/media-behaviors/media-behaviors.js";
import { SchemaBehaviors } from "@haxtheweb/schema-behaviors/schema-behaviors.js";

class VideoPlayer extends MediaBehaviorsVideo(SchemaBehaviors(LitElement)) {
  static get tag() {
    return "video-player";
  }

  static get properties() {
    return {
      ...super.properties,
      source: { type: String },
    };
  }

  set source(value) {
    // normalize a pasted share URL into a clean embed URL
    const type = this.getVideoType(value);
    this._source = this.cleanVideoSource(value, type);
  }

  get source() {
    return this._source;
  }

  render() {
    return html`
      ${this._sourceIsIframe(this.source)
        ? html`<iframe src="${this.source}"></iframe>`
        : html`<video src="${this.source}"></video>`}
    `;
  }
}
customElements.define(VideoPlayer.tag, VideoPlayer);
