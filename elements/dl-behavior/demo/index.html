dl-behavior

MtzFileDownloadBehaviors is a mixin (not a custom element) that adds client-side file download helpers to a LitElement class. It provides a fileTypes map of common MIME types (CSV, JSON, PDF, TXT, HTML) as well as two methods: downloadFromData(data, type, name, newTab), which converts string data to a Blob and triggers a browser download, and downloadFromURI(uri, newTab), which opens a URI in a new or existing tab to initiate a download.

Because this is a mixin function, there is no real <dl-behavior> element to instantiate. It is applied to another class via function composition, as shown below.

Usage example

import { LitElement, html } from "lit";
import { MtzFileDownloadBehaviors } from "@haxtheweb/dl-behavior/dl-behavior.js";

class MyExportButton extends MtzFileDownloadBehaviors(LitElement) {
  static get tag() {
    return "my-export-button";
  }

  exportCSV() {
    const csvData = "name,value\nfoo,1\nbar,2";
    this.downloadFromData(csvData, "CSV", "export");
  }

  render() {
    return html`<button @click="${this.exportCSV}">Download CSV</button>`;
  }
}
customElements.define(MyExportButton.tag, MyExportButton);

Note: this mixin does not currently appear to be consumed by any other element in the monorepo; usage above is illustrative and modeled after dl-behavior/test/dl-behavior.test.js, which is the only current consumer of the mixin.
