Buttons let people take an action. Use one filled button for the main action, and lower-emphasis buttons for the rest.

A filled button carries the primary color. A tonal button sits lower so it never competes with it.

Do

Start labels with a verb and keep them short.

Don't

Place two filled buttons side by side.
