This theme dresses a HAX site in Material 3 tokens. Authors keep the same blocks; the theme changes how they look.

Set up

Pick Material 3 in site settings, or set it in site.json.

Use headings, cards, notes and tabs. Each block reads DDD tokens.

Use the toggle in the top app bar to see the dark scheme.
