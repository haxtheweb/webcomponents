The token values on this site are generated from Material Design 3 (m3.material.io): the Sass token files in @material/web 2.5.0 (Apache-2.0): the reference palettes, the baseline light and dark color schemes, shape, motion, state and typeface. They are re-expressed under their upstream names. No Material 3 stylesheet is loaded.

Type is set in Roboto (SIL Open Font License 1.1) and Roboto Mono (Apache-2.0).

Coverage

The bridge maps 83 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 97%
  • Feel (motion, state opacities, control heights, border widths): 52%
  • Semantic (heading and body sizes): kept as DDD, so reading text stays at DDD sizes
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design

The full map ships as lib/material.ddd-map.json.
