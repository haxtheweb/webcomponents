This site runs on material-theme, a HAXcms theme in the Material 3 layout: a top app bar, a navigation drawer and a content surface. It sits on top of the Material 3 DDD bridge.

How the bridge works

Every HAX block reads DDD tokens such as --ddd-theme-default-beaverBlue, --ddd-font-primary and --ddd-radius-sm. While Material 3 is the active design system those tokens point at Material 3 tokens, so the whole block ecosystem takes on Material 3 colors, Roboto type, radii, shadows and focus rings without any block changing.

Content stays plain DDD content. Switch this site to any other theme and every page keeps working.
