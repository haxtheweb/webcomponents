DDD palettes are set with data-primary and data-accent. Each named DDD color points at the Material 3 palette color with the same role, so the palettes stay distinct.

DDD beaverBlue → Material 3 primary 40.

DDD nittanyNavy → Material 3 primary 20.

DDD creekTeal → Material 3 cyan 40.

DDD wonderPurple → Material 3 purple 30.

An accent surface: DDD slateMaxLight → Material 3 neutral-variant 95.

An accent surface: DDD limestoneMaxLight → Material 3 neutral 95.
