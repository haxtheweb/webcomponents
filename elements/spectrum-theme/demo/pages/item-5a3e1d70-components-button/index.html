Buttons let people take an action. Use one primary button for the main action on a page, and secondary buttons for everything else.

A primary button uses the accent color. A secondary button sits on a neutral fill so it never competes with the primary one.

Do

Start labels with a verb and keep them short: "Start the check", "Save draft".

Don't

Use more than one primary button in the same view, or a button for a link to another page.
