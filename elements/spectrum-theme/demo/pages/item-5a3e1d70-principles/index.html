These principles guide how the studio designs pages, courses and components. They describe what a good outcome looks like, so teams can make decisions without waiting for a review.

Rational

Every choice has a reason a reader could follow. Layout, color and type are applied by role, not by taste, so the same idea always looks the same.

Human

Pages are written for people with different needs, devices and levels of attention. Plain language, captions and keyboard access come first, not last.

Focused

Each page does one job. Supporting detail sits behind a disclosure, in a tab or on its own page, so the main path stays short.

Collaborative

Designers, authors and developers share one set of tokens and blocks. A change made once reaches every page that uses it.
