This theme dresses a HAX site in Spectrum 2 tokens. Authors keep writing with the same blocks; the theme changes how they look.

Set up

Pick Spectrum in site settings, or set it in site.json.

Use headings, cards, notes and tabs. Each block reads DDD tokens.

Use the theme toggle in the header. Every token has a light and a dark value.

Set the theme in site.json

Nothing in your pages refers to Spectrum. Switch themes and the same content renders in the new system.
