This site runs on spectrum-theme, a HAXcms theme in the Adobe Spectrum app frame: a header, a side navigation and a content panel. It sits on top of the Spectrum DDD bridge.

How the bridge works

Every HAX block reads DDD tokens such as --ddd-theme-default-beaverBlue, --ddd-font-primary and --ddd-radius-sm. While Spectrum is the active design system those tokens point at Spectrum tokens, so the whole block ecosystem takes on Spectrum colors, Source Sans 3 type, radii, shadows and focus rings without any block changing.

Content stays plain DDD content. Switch this site to any other theme and every page keeps working.
