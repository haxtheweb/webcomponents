The token values on this site are generated from Adobe Spectrum (spectrum.adobe.com): @spectrum-css/tokens 16.0.2 (Apache-2.0), the Spectrum 2 light and dark sets. They are re-expressed under their upstream names. No Spectrum stylesheet is loaded.

Type is set in Source Sans 3 and Source Code Pro, licensed under the SIL Open Font License 1.1. Spectrum's own face, Adobe Clean, is proprietary and is never loaded; Source Sans 3 is the open face its font stack falls back to.

Coverage

The bridge maps 84 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 97%
  • Feel (motion, state opacities, control heights, border widths): 57%
  • Semantic (heading and body sizes): kept as DDD, so reading text stays at DDD sizes
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design

The full map ships as lib/spectrum.ddd-map.json.
