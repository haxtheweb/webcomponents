DDD palettes are set with data-primary and data-accent. Each named DDD color points at the PatternFly palette color with the same role, so the 16 palettes stay distinct.

DDD beaverBlue → PatternFly blue 50.

DDD nittanyNavy → PatternFly blue 70.

DDD creekTeal → PatternFly teal 50.

DDD wonderPurple → PatternFly purple 60.

An accent surface: DDD slateMaxLight → PatternFly blue 10.

An accent surface: DDD limestoneMaxLight → PatternFly gray 10.
