Coverage

The bridge maps 82 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 92%
  • Feel (motion, borders; PatternFly has no state-opacity or control-height tokens): 43%
  • Semantic: density follows PatternFly spacers: 24px surface padding, 16px between blocks, 8px inline gaps. Heading and body sizes stay DDD, so reading text keeps DDD sizes.
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design, so authored layouts never move

The full map ships as lib/patternfly.ddd-map.json.
