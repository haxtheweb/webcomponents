sheet-music demo

Inline alphaTex with audio

Notation is authored as alphaTex in a slotted <template preserve-content>; audio playback is on by default. The alphaTab engine only loads when this scrolls into view. Dark mode follows your system preference automatically.

Viewer mode (audio off)

Omit audio (or set it to false) for a notation-only view.

MusicXML file — Ode to Joy (public domain)

Loads a local .xml (MusicXML) file — Beethoven's Ode to Joy, which is in the public domain. MusicXML is the open standard for sharing sheet music.

Guitar Pro file — Canon (hosted demo)

Loads a .gp (Guitar Pro 7) file from alphaTab's demo server. Guitar Pro files are proprietary but widely used for guitar tabs.

Display options and export hidden

show-display-options and show-export can be set to false to strip the control bar down to just play/pause/stop.
