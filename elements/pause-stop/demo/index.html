1. Penggunaan standar <langkah-bertahap> (slot bertahap)

Satu isi per langkah lewat slot="content-N". tombol "Lanjut..." membuka langkah berikutnya sampai langkah terakhir, tempat konfeti perayaan diluncurkan.

2. Label kustom dan dua langkah pertama sekaligus

button-label mengganti teks tombol utama, show-all-label mengganti label menu dropdown, dan visible-content="2" menampilkan dua langkah di awal.

3. Kompatibilitas tag <split-pause> (alias lama)

<split-pause> dan <warp-glitch> berbagi implementasi serta skema yang sama dengan <langkah-bertahap>, sehingga halaman lama tetap berjalan tanpa perubahan.

4. Fallback konten otomatis (tanpa slot eksplisit)

Konten di default slot menjadi langkah pertama, jadi tidak wajib menulis atribut slot untuk isi pertama.

5. Pemilih bahasa <language-picker>

Mengganti bahasa dokumen (<html lang> dan dir). i18n-manager mendeteksi perubahan itu, memuat ulang locales/langkah-bertahap.<lang>.json, lalu label tombol ikut berganti tanpa reload. Pilih العربية untuk melihat arah tulisan berubah menjadi RTL.
