ChatAgent: chat-agent demo

chat-agent is a floating chat widget built from a chat-button, chat-interface, chat-control-bar, chat-input, chat-message, and chat-suggestion team. It is a fixed-position widget, so it floats over the lower-right corner of the page instead of rendering inline. This demo is fully static: the greeting and the scripted sample exchange below are handled offline by the element itself.

chat-agent over sample page content

Offline prompts to try

The suggested prompts below are answered entirely offline, so you can exercise the full conversation flow without any network activity:

  • Who are you?
  • What can you do for me?
  • How do I use you?

Use the chat control bar to download the chat log, reset the conversation, or toggle the full view mode with the expand button.
