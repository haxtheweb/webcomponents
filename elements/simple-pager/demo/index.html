simple-pager

A reusable, presentational pager that mirrors a backend PageInfo shape (limit, offset, total) and fires a single bubbling page-changed event with { limit, offset }. It owns no data fetching; the consumer re-issues its request and reflects the new offset back.

Inline / mini mode

A compact Previous / Next control with a terse status string, suited to narrow toolbars and inline widgets.
