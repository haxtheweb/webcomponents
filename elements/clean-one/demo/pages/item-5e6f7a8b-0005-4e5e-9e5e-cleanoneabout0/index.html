About This Course

This site exists to demonstrate clean-one, the original HAXcms course theme. clean-one renders the course outline as a navigation menu, presents page content in a readable single-column layout, and includes the standard HAXcms site furniture such as the site title, print support, and routing.

About the Theme

clean-one is a lightweight theme that pairs well with text-first course content. It is fully dark-mode aware, works with the HAX design system tokens, and requires no build step to run.

Every page in this demonstration, including this one, is plain HTML content that the theme loads based on the site outline.
