Welcome to the Course

This course is a demonstration site rendered by clean-one, the foundational HAXcms course theme. Everything you see here, from the navigation outline to the page content, is driven by a single site outline.

How This Course Works

  • Use the navigation menu to move between the course overview, units, lessons, and resources.
  • Each page of the course lives at its own address, generated from the outline structure.
  • Units can contain nested lessons, and the menu reflects that hierarchy.

Start with Unit 1 to see how a nested lesson appears in the menu, then visit the Course Resources page for reference material.
