A Short History

In November 1995 Vermeer Technologies shipped the FrontPage 1.0 editor, one of the first tools that let people build web pages by seeing them instead of typing tags. In January 1996 Microsoft bought Vermeer, and in June 1996 it released Microsoft FrontPage 1.1.

The idea was simple and radical: the page you edit is the page people see. HAX chases that same idea, with web components standing in for the old bots and templates.

The Windows

Explorer holds the site outline. The page window shows the page's file in its title bar, the site's top pages as a menu bar, and a toolbar of site actions: previous and next page, print, search, View HTML and high contrast.

The title bar buttons work the way they did: the bar on the left rolls a window up to its title, the down arrow minimizes it to an icon on the desktop, and the up arrow maximizes the page window. View HTML shows the page source as saved (Original) or as the browser draws it now (Generated), and you can drag its title bar to move it.

Try It

  1. Turn on High Contrast in the toolbar for the high contrast black scheme.
  2. Minimize the page window, then open it again from its desktop icon.
  3. Log in and press Edit: the editor takes on the same look.
