Classic Desktop carries a HAX UI skin, so the editor joins in when a site uses it.

Changes

  • The top bar is a navy title bar
  • The tray, menus and dialogs are classic gray windows
  • Square corners and the classic sans serif
  • A high contrast black scheme in dark mode

Stays the same

  • Every label, menu and shortcut
  • Every editing capability and its order
  • Saving, outline and site settings
  • Keyboard and screen reader behavior
 Pick another design system in site settings and the windows keep their shape in its colors and type. Content stays plain DDD content, so it moves to any theme unchanged.
