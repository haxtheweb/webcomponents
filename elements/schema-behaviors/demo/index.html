schema-behaviors

SchemaBehaviors is a mixin (not a custom element) that wires an element into the OER Schema / schema.org RDFa vocabulary. On construction it establishes a schemaMap of common prefixes (oer, schema, dc, foaf, cc, bib). When schemaMap updates, it ensures the host element has a stable resource attribute (generating one with generateResourceID() if needed) and sets a prefix attribute built from the configured namespaces, so downstream RDFa/structured-data tooling can resolve schema terms against the element.

Because this is a mixin function, there is no real <schema-behaviors> element to instantiate. It is applied to another class via function composition, as shown below with two real consumers in this monorepo: oer-schema and self-check.

Usage example (adapted from oer-schema.js)

import { LitElement, html, css } from "lit";
import { SchemaBehaviors } from "@haxtheweb/schema-behaviors/schema-behaviors.js";

class OerSchemaElement extends SchemaBehaviors(LitElement) {
  static get tag() {
    return "oer-schema";
  }

  constructor() {
    super();
    this.text = "";
    this.oerProperty = "name";
    this.typeof = "Resource";
  }

  render() {
    return html`
      <span property="oer:${this.oerProperty}">
        <slot></slot> ${this.text}
      </span>
    `;
  }
}
customElements.define(OerSchemaElement.tag, OerSchemaElement);
