lrn-math demo

lrn-math renders LaTeX in place using MathJax, which the element loads from its CDN when the first equation connects. Math written directly in the tag renders inline by default; set mode to display for block rendering, or drive the equation through the mathtext attribute, which is also how the HAX editor keeps the source text in sync.
