simple-filter

SimpleFilterMixin is a mixin (not a custom element) that adds filtering capabilities to a LitElement class. It manages items, where, like, caseSensitive, and multiMatch properties, and debounces a filtered computation whenever any of those change, dispatching filter and filtered-changed events with the results.

Note: the file also defines a local SimpleFilter class for convenience, but it is never registered with customElements.define, so there is no real <simple-filter> element to instantiate. The mixin is applied to another class via function composition, as demonstrated by the real consumer simple-autocomplete.

Usage example (adapted from simple-autocomplete.js)

import { LitElement, html } from "lit";
import { SimpleFilterMixin } from "@haxtheweb/simple-filter/simple-filter.js";

class SimpleAutocomplete extends SimpleFilterMixin(LitElement) {
  static get tag() {
    return "simple-autocomplete";
  }

  processInput(value) {
    this.opened = true;
    this.value = value;
    // setting `like` triggers the mixin's debounced filter computation
    this.like = this.value;
  }

  render() {
    return html`
      ${this.filtered.map(
        (item) => html`<li>${item.label}</li>`,
      )}
    `;
  }
}
customElements.define(SimpleAutocomplete.tag, SimpleAutocomplete);

// consumer sets items and listens for the mixin's events
const el = document.querySelector("simple-autocomplete");
el.items = [{ label: "Option 1", value: 1 }, { label: "Option 2", value: 2 }];
el.addEventListener("filtered-changed", (e) => console.log(e.detail.value));

See simple-autocomplete/simple-autocomplete.js for the full real-world implementation.
