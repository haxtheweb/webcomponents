About This Blog

The Haxor Journal is a demonstration site for haxor-slevin, a HAXcms blog theme. The theme renders the home page as a listing of posts with paging, presents each post as a full article, and keeps the about page for author background.

About the Theme

haxor-slevin is built entirely from web components and design tokens. It is dark-mode aware, responsive from phones to desktops, and every bit of styling on display here comes from the theme itself rather than the page content.
