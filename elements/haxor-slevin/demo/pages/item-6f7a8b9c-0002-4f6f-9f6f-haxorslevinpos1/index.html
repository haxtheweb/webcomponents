Shipping Web Components Without a Build Step

Every page of this blog, including this post, is plain HTML loaded from a site outline. There is no bundler, no compile step, and no toolchain between what gets written and what the browser downloads.

Why It Matters

When a site ships as native web standards, it stays runnable long after the tooling that produced it has moved on. That longevity is the whole point. A static outline, custom elements defined in plain JavaScript, and CSS custom properties for theming are all it takes.

  • Pages load directly from the outline, so content stays portable.
  • Theme styling flows through design tokens rather than compiled classes.
  • Anyone can read the source and understand the whole system.

The tradeoff is discipline instead of guardrails, and for a personal site that is a trade worth making.
