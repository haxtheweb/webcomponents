Notes on the Open Web

Standards outlive frameworks. Semantic HTML written today will still render decades from now, which is a stronger guarantee than most software can make.

Three Habits Worth Keeping

  • Write semantic markup first, then style it.
  • Test with the keyboard before reaching for the mouse.
  • Prefer plain formats that outlive the platform that made them.
