Coverage

The bridge maps 85 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 99%
  • Feel (motion, state opacities, control heights, border widths): 30%
  • Semantic (density and heading sizes): 42%; card and control padding follow Web Awesome, reading sizes stay DDD
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design
