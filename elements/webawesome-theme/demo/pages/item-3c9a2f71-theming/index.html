Palettes

DDD palettes are set with data-primary and data-accent. Web Awesome's palettes are tuned so a step number means the same lightness in every hue, so the text color DDD puts on each palette passes contrast in all of them.

Primary 1

DDD beaverBlue → blue 50, the brand key color.

Primary 7

DDD creekTeal → cyan 70, with dark text.

Primary 15

DDD inventOrange → orange 70.

Primary 13

DDD wonderPurple → purple 40.

An accent surface: DDD slateMaxLight → gray 95.
