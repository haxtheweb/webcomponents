# LrndesignChart

Accessible bar, line and pie charts (lrndesign-bar, lrndesign-line, lrndesign-pie) drawn from a CSV data source with Chartist.

- Package `@haxtheweb/lrndesign-chart` 26.8.0

## Usage

```html
<lrndesign-bar data-source="data/bar.csv" chart-title="Bar chart" chart-desc="Demo values from bar.csv" accent-color="blue"></lrndesign-bar>
<lrndesign-pie data-source="data/pie.csv" chart-title="Pie chart" chart-desc="Demo values from pie.csv" accent-color="orange"></lrndesign-pie>
```
