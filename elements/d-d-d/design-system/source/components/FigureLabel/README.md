# FigureLabel

Figure label element to mark media assets within content.

- Package `@haxtheweb/figure-label` 26.8.0
- HAX block "Figure label" (Content, figure, a11y, accessibility, image)

## Usage

```html
<figure-label title="1.3" description="Microbes under a microscope"></figure-label>
<figure-label accent-color="red" title="1.4" description="Accent color enabled"></figure-label>
```
