# HaxTheme_CleanOne

Clean HAXcms theme, one.

- Package `@haxtheweb/clean-one` 26.8.0

## Using it

A HAXcms theme. Select it in a site's `site.json` (`metadata.theme.element: "clean-one"`). The preview boots the theme's own demo site with `haxcms-site-builder`; the site ships under `runtime/sites/clean-one/`.

Themes extend `HAXCMSLitElement` with DDD and must follow the theme-header contract in the pattern library.

## DDD usage

Its source references 44 distinct design-system variables. By family: palette (51), lightDark (39), spacing (8), theme (6), simple-colors (4), font (4). Most used: `--ddd-lightDark-1`, `--ddd-lightDark-7`, `--ddd-palette-dark`, `--ddd-palette-7`, `--ddd-lightDark-2`, `--ddd-lightDark-6`.
