# HaxTheme_CleanTwo

A 2nd clean theme.

- Package `@haxtheweb/clean-two` 26.8.0

## Using it

A HAXcms theme. Select it in a site's `site.json` (`metadata.theme.element: "clean-two"`). The preview boots the theme's own demo site with `haxcms-site-builder`; the site ships under `runtime/sites/clean-two/`.

Themes extend `HAXCMSLitElement` with DDD and must follow the theme-header contract in the pattern library.

## DDD usage

Its source references 26 distinct design-system variables. By family: accent (32), primary (29), spacing (16), font (11), theme (7), icon (6). Most used: `--ddd-accent-6`, `--ddd-primary-4`, `--ddd-spacing-5`, `--ddd-theme-default-black`, `--ddd-icon-xxs`, `--ddd-border-sm`.
