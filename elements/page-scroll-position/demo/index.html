page-scroll-position demo

page-scroll-position is a headless element that tracks how far the user has scrolled through the whole document. It stores the percent scrolled in its value property and fires a value-changed event on every scroll, so progress bars and reading indicators can bind to it.

Basic usage

The element renders nothing on its own. Drop it on the page and listen for value-changed to react to scroll position.
