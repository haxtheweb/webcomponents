DDD palettes are set with data-primary and data-accent. Each named DDD color points at the shadcn/ui palette color with the same role, so the palettes stay distinct.

DDD beaverBlue → shadcn/ui neutral 900.

DDD nittanyNavy → shadcn/ui neutral 800.

DDD creekTeal → shadcn/ui teal 600.

DDD wonderPurple → shadcn/ui purple 800.

An accent surface: DDD slateMaxLight → shadcn/ui slate 50.

An accent surface: DDD limestoneMaxLight → shadcn/ui neutral 50.
