This site runs on shadcn-theme, a HAXcms theme in the shadcn/ui sidebar layout: a sidebar, an inset panel and a header with a breadcrumb. It sits on top of the shadcn/ui DDD bridge.

How the bridge works

Every HAX block reads DDD tokens such as --ddd-theme-default-beaverBlue, --ddd-font-primary and --ddd-radius-sm. While shadcn/ui is the active design system those tokens point at shadcn/ui tokens, so the whole block ecosystem takes on shadcn/ui colors, Geist type, radii, shadows and focus rings without any block changing.

Content stays plain DDD content. Switch this site to any other theme and every page keeps working.
