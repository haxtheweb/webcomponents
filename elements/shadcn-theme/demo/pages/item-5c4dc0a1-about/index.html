The token values on this site are generated from shadcn/ui (ui.shadcn.com): the default (neutral) theme shadcn init writes, from the shadcn-ui/ui repository at commit dd41d19e (MIT; pinned and verified by sha256), on the tailwindcss 4.3.5 palette (MIT). They are re-expressed under their upstream names. No shadcn/ui stylesheet is loaded.

Type is set in Geist and Geist Mono, licensed under the SIL Open Font License 1.1.

shadcn/ui is a project by shadcn. This theme is an independent HAX integration and is not affiliated with or endorsed by shadcn.

Coverage

The bridge maps 77 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 100%
  • Feel (motion, state opacities, control heights, border widths): 17%
  • Semantic (heading and body sizes): kept as DDD, so reading text stays at DDD sizes
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design

The full map ships as lib/shadcn.ddd-map.json.
