Why I Blog with Plain HTML

A blog is mostly text, so the machinery behind it should be as simple as the content. This site is a folder of HTML pages, an outline that orders them, and a theme that renders them.

The Benefits

  • The writing is the source of truth, in a format that will outlive any platform.
  • Pages stay tiny, which keeps the site fast on any connection.
  • Fixes happen in the open, one file at a time.

When the goal is to keep writing for years, the boring option is the one that still works in a decade.
