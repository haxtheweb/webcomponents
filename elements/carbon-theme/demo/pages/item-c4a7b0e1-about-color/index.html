DDD palettes are set with data-primary and data-accent. Each named DDD color points at the IBM Design Language palette color with the same role, so the palettes stay distinct.

DDD beaverBlue → Carbon blue 60.

DDD nittanyNavy → Carbon blue 80.

DDD creekTeal → Carbon teal 50.

DDD wonderPurple → Carbon purple 70.

An accent surface: DDD slateMaxLight → Carbon cool gray 10.
