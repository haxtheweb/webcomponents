Coverage

The bridge maps 90 DDD tokens against the shared DDD bridge contract:

  • Identity (colors, fonts, weights, radius, shadows, focus): 97%
  • Feel (motion and control heights; Carbon uses hover colors rather than state opacities): 61%
  • Semantic: density follows Carbon's spacing steps, which match DDD's: 16px surface padding and stack gap, 8px inline gaps. Heading and body sizes stay DDD, so reading text keeps DDD sizes.
  • Structure (spacing, type scale, line height, layout widths): locked to DDD by design. Carbon's spacing scale sits on the same 4px grid.

The full map ships as lib/carbon.ddd-map.json.
