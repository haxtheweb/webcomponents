This site runs on carbon-theme, a HAXcms theme in the IBM Carbon UI Shell layout: a dark header, a side navigation and a content area. It sits on top of the Carbon DDD bridge.

How the bridge works

Every HAX block reads DDD tokens such as --ddd-theme-default-beaverBlue, --ddd-font-primary and --ddd-radius-sm. While Carbon is the active design system those tokens point at Carbon tokens, so the whole block ecosystem takes on Carbon colors, IBM Plex type, radii, shadows and focus rings without any block changing.

Content stays plain DDD content. Switch this site to any other theme and every page keeps working.
