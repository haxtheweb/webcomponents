What makes HAX, HAX?

Every HAX block is a standard web component, so a page is plain HTML that any browser can read. The editor checks headings, alternative text and captions while you write, which means pages work with a screen reader from the moment they are made instead of being fixed later.

A HAX site is a folder of files: a site.json outline, the HTML of each page, and the images and media those pages use. The same folder runs in HAXcms on Node.js or PHP, publishes as static pages, or copies to any web server. Anyone can duplicate a site, switch its theme, or reorganize its outline without rebuilding a thing.

Elements load only when a page uses them, so pages stay small and quick on older phones and slow connections, which also means less data and less battery. The whole project is Apache-2.0 licensed and built in the open, and new themes, blocks and plugins plug in without touching the core.
