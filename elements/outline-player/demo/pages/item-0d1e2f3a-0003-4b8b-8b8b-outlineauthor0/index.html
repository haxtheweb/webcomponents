Authoring Content

Every page on this site is a plain HTML file whose location is recorded in the site outline. This page, for example, is a child of the User Guides section, so the breadcrumb above shows the full path to it.

How a Page Is Structured

  • Write the page as semantic HTML, starting with second-level headings for sections.
  • Record the page in the outline with a title, description, and location.
  • Nest the page under a section when it belongs to one, and the hierarchy appears in navigation.

Because pages are plain HTML, any editor can author them and any static host can serve them.
