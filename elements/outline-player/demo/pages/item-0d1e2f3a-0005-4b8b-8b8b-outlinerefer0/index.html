Outline Reference

The site outline is a single JSON file that describes every page on the site. Navigation, routing, and page loading all derive from it.

Item Fields

  • id - a unique identifier for the page.
  • title - the page title, shown in navigation and at the top of the page.
  • slug - the address of the page, used for routing.
  • location - the path to the HTML file that holds the page content.
  • parent - the id of the section the page nests under, or null for top-level pages.
  • order - the position of the page among its siblings.

Change the outline and the whole site follows, which is what makes the outline the single source of truth for a HAXcms site.
