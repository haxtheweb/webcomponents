About Outline Player

outline-player is a HAXcms theme for presenting outlined content. It renders the site outline as a persistent navigation drawer, keeps breadcrumbs and previous and next controls within reach, and includes search and print support.

Highlights

  • Persistent outline navigation that collapses on small screens.
  • Breadcrumbs and previous and next buttons for moving through the outline in order.
  • Dark mode support that follows the system preference.
  • Built from web components and design tokens with no build step required.

This documentation site is itself a demonstration: every page in it, this one included, is loaded from the outline that the player presents.
