# primer-theme

A HAXcms theme in the layout of the Primer documentation site, [primer.style](https://primer.style), built on the **Primer DDD bridge**:

- **Header**: 64px on `bgColor-default` with a `borderColor-default` hairline, and Primer icon buttons for the menu, search and dark mode.
- **Sidebar**: a NavList on the default background; the current item is a 6px-rounded muted pill with Primer's 4px accent bar. Below 1012px it overlays the page.
- **Content**: a 1012px column opening with the breadcrumb, a semibold title and the page description as a muted lead under a hairline. Previous and next close the page.

## What the bridge does

HAX blocks only read DDD tokens (`--ddd-*`). This package re-expresses Primer's functional tokens under their own names (`--fgColor-default`, `--bgColor-muted`, `--borderColor-default`, ...) and points every DDD token a block reads at the closest Primer token. While this theme is active, blocks take on Primer color, Mona Sans, 6px corners, Primer shadows, its focus outline, motion and control heights. Authored content stays plain DDD content that renders in any other theme.

The design system registers as `primer` with `extends: "ddd"` in `DesignSystemManager`, so DDD's styles, data attributes and HAX authoring options stay in place. A site can also keep its own theme and choose Primer as its design system.

| File | What it is |
|---|---|
| `design-system/bridge.json` | The authored mapping: `@primer/primitives` CSS sources, the Mona Sans font, icons, and each DDD token → Primer token |
| `lib/PrimerTokens.js` | Generated: the Primer tokens the map and theme use, as `light-dark()` pairs |
| `lib/PrimerDDDMap.js` | Generated: the `--ddd-*` → Primer remap |
| `lib/PrimerIcons.js`, `icons/` | Generated: HAX icon names drawn in Octicons |
| `lib/primer.ddd-map.json` | Generated: the full map with resolved values, coverage per contract tier and a contrast report |
| `lib/PrimerDesignSystem.js` | Registers and activates the `primer` design system |
| `primer-theme.js` | The theme |

## Coverage

Checked against the shared [bridge contract](../d-d-d/design-system/bridge/README.md): identity 97%, feel 61%, semantic 42% (density: 16px surface padding and stack gap, 8px inline gap), component 100%, structure locked. Primer's colors exist per color mode, so named DDD colors take the light theme's value as a constant (`fromMode`); the theme chrome uses the functional tokens, which follow light and dark. Primer's sizes are rem and HAX's root font size is 20px, so radii and control heights are written in px. Kept as DDD on purpose: black font weight, state opacities, border widths and heading/body sizes (Primer body is 14px, under the 16px floor).

## Rebuilding the tokens

```
yarn ddd:bridge elements/primer-theme          # from the monorepo root
yarn ddd:bridge elements/primer-theme --check  # fail if the generated files are stale
```
