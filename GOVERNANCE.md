# Governance

This repository follows the HAX governance model (source of truth for `haxtheweb/*`):
https://github.com/haxtheweb/issues/blob/master/GOVERNANCE.md

Roles, decision-making (the unified issue queue + `Plan Created` plans), the maintainer lifecycle, succession, and conflict-of-interest/vendor participation are documented there.

To propose changes to governance: open an issue in the unified queue https://github.com/haxtheweb/issues/issues
