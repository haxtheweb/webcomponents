# Sustainability

This repository follows the HAX sustainability model (source of truth for `haxtheweb/*`):
https://github.com/haxtheweb/issues/blob/master/SUSTAINABILITY.md

It documents the funding model (Penn State stewardship + hosting partners), what free community support does and does not cover, resource needs, and the infrastructure inventory behind the ecosystem.

To help carry the maintenance load: see CONTRIBUTING.md — dependency PRs, doc fixes, and issue triage are as valuable as features.
